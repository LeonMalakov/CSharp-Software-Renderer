# C# Software Renderer

A simple software-based 3D renderer built from scratch in C#, without using a graphics API for rendering.

**Features:**

- Triangle rasterization and Z-buffer depth testing
- Model, view, and projection transformations
- Back-face culling and basic directional lighting
- OBJ model loading
- Simple scene editor built with Windows Forms
